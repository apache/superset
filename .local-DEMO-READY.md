## The flow to walk

1. **As maker** — open a dashboard, edit, Save. The toast says viewers still
   see the live version; nothing has gone live.
2. **As maker** — Request review.
3. **As checker** — the bell counts it; the popover lists it;
   **Approvals** shows it as "Needs your review".
4. **As checker** — Review takes you to the dashboard: banner across the
   top, panel on the right with the field diff, Show changes, Open live
   version.
5. **As checker** — Approve (it asks first), or Request changes to send it
   back to maker.
6. **As maker** — a returned change shows in the bell as "returned".

Datasets are reviewed from the Approvals list itself (dataset editor tabs,
read-only), because a dataset has no page of its own.

## What changed vs the recorded demo

The Approvals and Change review screens are now **contributed pages** served
by the extension, not core routes. Everything else — the bell, Pending
reviews on Home, the dashboard banner and panel, the list tags, the gate —
is unchanged.

The Approvals page is open to everyone in the workflow — Admin, Alpha and
Gamma — the same roles that could open it before the move. The extension
grants its page permission to whoever holds `can_read on ChangeRequest`,
because the host grants a contributed page's permission to Admin only and
cannot know who an extension means its page for.

Both screens now sit in **Settings → Manage**, where the mocks put them
(16c and S1), not in the top navigation bar. The bell is the primary way
in, as the design intends, and "View all approvals" still reaches the list.

One difference from the recording remains:

- **No red count on the Settings entry.** Mock 16c wants the count there
  to match the bell. Superset's menu entries carry no badge, so that needs
  a new capability rather than a placement. The bell itself still counts.

- **There is no per-change-request page.** `/approvals/<id>/` is gone: the
  mocks have no such screen, and review happens on the asset (9-12) or,
  for a dataset, from the list (13). Links that used to point there now
  open the list.
