1. Background

Superset's existing PDF report pipeline takes a PNG screenshot of the rendered dashboard and wraps it in a PDF container using PIL. This produces raster-only output: no selectable text, no real links, large file sizes, and clipped content for off-screen widgets.

SIP-212 proposes replacing step 5–6 of that pipeline (screenshot → image-in-PDF) with Playwright's native page.pdf() on a print-ready DOM. This branch implements Phases A–C of the hybrid approach described in the design documents.

4.2 New JS readiness predicate — superset/utils/screenshot_utils.py EXTEND

Added after the existing REPORT_CHART_HOLDERS_READY_JS constant. The existing predicate skips chart holders outside the viewport (getBoundingClientRect() filter). The new one removes that filter so ALL holders in the DOM must reach terminal state — required because page.pdf() renders the full document, not just the visible viewport.

PRINT_ALL_CHART_HOLDERS_READY_JS_BODY = f"""
    const holders = document.querySelectorAll('{CHART_HOLDER_SELECTOR}');
    const unready = [];
    for (const holder of holders) {{
        const stillLoading = holder.querySelector('{LOADING_SELECTOR}') !== null;
        const isReady = holder.querySelector('{TERMINAL_MARKER_SELECTOR}') !== null;
        if (stillLoading || !isReady) {{
            const chartIdMatch = holder.className.match(/{CHART_ID_CLASS_PATTERN}/);
            unready.push({{ chartId: chartIdMatch ? chartIdMatch[1] : null }});
        }}
    }}
"""
PRINT_ALL_CHART_HOLDERS_READY_JS = (
    f"() => {{ {PRINT_ALL_CHART_HOLDERS_READY_JS_BODY} "
    "return holders.length > 0 && unready.length === 0; }"
)

4.3 New DashboardPrintScreenshot class — superset/utils/screenshots.py NEW

Appended after DashboardScreenshot. Subclass that appends ?print=1 to the URL (on top of ?standalone=3 set by the parent) and exposes a get_print_pdf() method:

class DashboardPrintScreenshot(DashboardScreenshot):
    def __init__(self, url, digest, window_size=None, thumb_size=None):
        super().__init__(url, digest, window_size, thumb_size)
        self.url = modify_url_query(self.url, print=1)

    def get_print_pdf(self, user, window_size=None,
                      log_context=None, report_execution_context=None):
        if not feature_flag_manager.is_feature_enabled(
                "PLAYWRIGHT_REPORTS_AND_THUMBNAILS"):
            return None
        if not PLAYWRIGHT_AVAILABLE:
            return None
        driver = WebDriverPlaywright(self.driver_type,
                                     window_size or self.window_size)
        return driver.get_print_pdf(self.url, user=user,
            log_context=log_context,
            report_execution_context=report_execution_context)

4.4 New get_print_pdf() method — superset/utils/webdriver.py NEW

Added to WebDriverPlaywright (after get_screenshot()). Also added PRINT_ALL_CHART_HOLDERS_READY_JS to the existing import from screenshot_utils.

The method: opens an authenticated browser context, navigates to the print URL, waits for .standalone to mount, then polls PRINT_ALL_CHART_HOLDERS_READY_JS until all chart holders reach terminal state, then calls page.pdf(format="A4", print_background=True, margin=10mm). Any exception returns None (never raises) so the caller can fall back.

4.5 Worker routing — superset/commands/report/execute.py EXTEND

Two changes:

def _get_pdf(self) -> bytes:
    if (feature_flag_manager.is_feature_enabled(
            "DASHBOARD_REPORTS_BROWSER_PRINT_PDF")
            and self._report_schedule.dashboard):
        try:
            pdf_bytes = self._get_browser_print_pdf()
            if pdf_bytes:
                return pdf_bytes
        except Exception:  # noqa: BLE001
            logger.exception("browser_print_pdf_exception ...")
    # EXISTING PATH — unmodified
    screenshots = self._get_screenshots()
    ...

def _get_browser_print_pdf(self) -> bytes | None:
    urls = self.get_dashboard_urls()
    if len(urls) != 1:   # multi-tab deferred
        return None
    screenshot = DashboardPrintScreenshot(urls[0], ...)
    return screenshot.get_print_pdf(user=user, ...)

4.11 Chart title link suppression — superset-frontend/src/dashboard/components/SliceHeader/index.tsx BUG FIX

Discovered during testing: chart titles were rendered as clickable <a href> links in the PDF (clicking "Total Revenue" opened Chrome at an explore URL). Root cause: renderExploreLink wraps the title in a React Router <Link> when canExplore is true. Fixed by adding && !isPrintMode:

import { URL_PARAMS } from 'src/constants';
import { getUrlParam } from 'src/utils/urlUtils';

// inside component:
const isPrintMode = getUrlParam(URL_PARAMS.print) === 1;
const canExplore = !editMode && supersetCanExplore && !isPrintMode;

4.12 Inactive tab rendering — superset-frontend/src/dashboard/components/gridComponents/Tabs/Tabs.tsx BUG FIX

Discovered during testing: the PDF only contained the active tab. Root cause: isComponentVisible is passed as selectedTabIndex === tabIndex && isCurrentTabVisible — only the active tab gets true, so inactive tab charts are never mounted in the DOM. Fixed:

import { URL_PARAMS } from 'src/constants';
import { getUrlParam } from 'src/utils/urlUtils';

// in the tab items useMemo:
isComponentVisible={
  getUrlParam(URL_PARAMS.print) === 1
    ? true
    : selectedTabIndex === tabIndex && isCurrentTabVisible
}

5. Fallback Guarantee

The existing screenshot path is completely untouched. The new path is purely additive:

Flag OFF → existing path runs, no change
Flag ON + multi-tab dashboard → returns None → existing path
Flag ON + Playwright unavailable → returns None → existing path
Flag ON + readiness timeout → PlaywrightTimeout caught → returns None → existing path
Flag ON + page.pdf() error → caught → returns None → existing path
Flag ON + pdf_bytes returned → new path used, logged as browser_print_pdf_used

7. Known Limitations (Out of Scope)

ItemWhy deferred
ECharts canvas text (axis labels, legends) not selectableCanvas is a raster bitmap — text is pixels, not DOM. Unavoidable without switching ECharts to SVG rendering mode.
Multi-tab dashboards (tabs split into separate URLs)Requires per-URL page.pdf() + PDF merge library (pypdf). Explicitly deferred as Phase 5.
Large table server-side fetch pathCSS overflow expansion sufficient for moderate tables. Phase D deferred.
A4 format hard-codedConfigurable format is a Phase 4 hardening item.
Selenium print PDFSelenium has no page.pdf() equivalent. Hard requirement on Playwright.
