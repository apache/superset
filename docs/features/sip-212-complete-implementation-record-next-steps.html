  • No any TypeScript types, no JavaScript files — TypeScript only, properly typed.

  • docker/pythonpath_dev/superset_config_docker.py is gitignored (catch-all * in docker/pythonpath_dev/.gitignore) — never goes into the PR, no revert needed.

  • The worker container (superset-superset-worker-1) runs its own .venv pip install, NOT the source mount — run all test scripts from superset-superset-1 (the web container).
  • Playwright test scripts must use http://superset:8088 as the base URL (Docker internal hostname). localhost from inside the container resolves to the container's own loopback — the web server is NOT there.
  • After any npm run build failure or stale-manifest issue: check that every JS hash in superset/static/assets/manifest.json has a matching file in superset/static/assets/. A mismatch means the bundle is from a different build session and the SPA will silently fail to mount.

1. What the Feature Does (End-to-End Flow)

Replaces raster-screenshot-stitched PDFs with Playwright's native page.pdf() — a real vector PDF with selectable text. The new path is strictly additive; any failure falls back silently to the existing screenshot path.

1. Celery worker → execute.py::_get_pdf()
↓
2. Flag check: DASHBOARD_REPORTS_BROWSER_PRINT_PDF=True AND dashboard report AND single-URL → _get_browser_print_pdf()
↓
3. DashboardPrintScreenshot.__init__ builds URL: base URL + ?standalone=3&print=1 (+ &print_font_size=medium|large if non-small tier)
↓
4. Playwright navigates (viewport=1600px wide), authenticates via machine_auth_provider_factory, waits for .standalone
↓
5. Frontend sees ?print=1: DashboardBuilder adds body.print-mode + injects PRINT_MODE_CSS + getPrintFontSizeCSS(tier) as a single style tag. Row.tsx bypasses IntersectionObserver. Tabs.tsx sets forceRender:true. SliceHeader disables chart-title links.
↓
6. UNHIDE_TAB_PANELS_JS: strips inline style="display:none" from all [role="tabpanel"] elements
↓
7. PRINT_ALL_CHART_HOLDERS_READY_JS waits until ALL chart holders (not just viewport-visible) reach terminal state
↓
8. UNHIDE_TAB_PANELS_JS again (safety net). EXPAND_TABLE_CONTAINERS_JS removes inline height/overflow from table scroll containers. SET_PRINT_FONT_SIZE_JS(px) patches inline font-size on .header-line elements for medium (64px) and large (96px) tiers.
↓
9. Reads BROWSER_PRINT_PDF_HEADER_CONTENT and BROWSER_PRINT_PDF_FOOTER_CONTENT from app config. Builds header/footer templates with token-expanded, HTML-escaped slot content.
↓
10. page.pdf(format="A4", scale=794/1600, margins=18mm/15mm/10mm/10mm, display_header_footer=True, header_template=..., footer_template=...)
↓
11. Return bytes → caller. Any exception → return None → fall back to screenshot path

4. All Compromises & Path to Final Implementation

The feature is working for single-URL dashboards. The gaps below are known.

C1 — Multi-URL dashboards silently fall back deferred

Dashboards with top-level tabs produce multiple URLs. _get_browser_print_pdf() returns None if len(urls) != 1. Phase 5 fix: iterate all URLs, merge PDFs with pypdf.PdfWriter.

C2 — JS DOM mutation is fragile works but not ideal

UNHIDE_TAB_PANELS_JS mutates the DOM from outside React. Definitive fix: pass a React context signal to CSSMotion so it never enters the forceRender+display:none branch in print mode.

C3 — No chart-type safety limits not started

No block-list for chart types that may not render headlessly (DeckGL WebGL). No page-count cap. Add BROWSER_PRINT_PDF_CHART_TYPE_BLOCKLIST and BROWSER_PRINT_PDF_MAX_PAGES config keys.

C4 — Python unit tests need a venv to run tests written, runner on host missing

Tests at tests/unit_tests/utils/test_browser_print_pdf.py can be run inside Docker: docker exec superset-superset-1 python3 -m pytest tests/unit_tests/utils/test_browser_print_pdf.py -v.

C5 — pre-commit must be run before PR pending

Per AGENTS.md this is mandatory. See Section 5 for the exact command.

C6 — ECharts SVG/canvas labels not font-size-controllable known limitation

ECharts renders axis ticks, legend, pie labels onto SVG/canvas with inline font attributes. CSS cannot reach them; JS cannot patch them post-render without re-rendering. Font-size tiers only affect DOM elements: chart titles, table cells, markdown, Big Number values.
